# 💡 Digital Logic Design – RTL Design, Simulation & Synthesis

This repository includes all major Verilog-based assignments from the **Digital Logic Design** course at the **University of Tehran**. The projects range from basic gate-level design to combinational and sequential RTL architectures, synthesized on FPGA platforms.

---

## 📁 Folder Overview

### 🔲 Accelerator RTL Design
- RTL implementation of a **cos(x)** accelerator using **Taylor Series** and **FSM-based control**.
- Includes: datapath, controller, testbench, synthesis outputs.

### ⚙️ Basic Switch and Gate Structures
- Transistor-level and gate-level design of logic circuits (e.g., **One's Counter**).
- Comparison of designs at transistor, gate, and behavioral levels.

### 🔗 Combinational RTL Design, Simulation, and Synthesis
- Design of a **16-bit ALU** supporting multiple operations using opcodes.
- Two approaches: behavioral + hardware-oriented.
- Fully synthesized and simulated using Yosys.

### 🔁 Latches and Flip-Flops
- Implementation and timing analysis of **SR latches** and **D flip-flops**.
- Focus on setup/hold time violations, clocking, asynchronous PRE/CLR control.

### 🟠 Latches and Flip-Flops Quartus
- Same as above, adapted and implemented inside **Intel Quartus II**.
- Timing waveforms, RTL netlists, and synthesized reports included.

---

## 🧠 Topics Covered

- RTL Design in Verilog
- FSM-based Controller Modeling
- Arithmetic Logic Units (ALUs)
- Sequential Circuit Design (DFF, SR-Latch)
- Gate-level Timing Delays
- Synthesis (Yosys/Quartus)
- Testbenching and Simulation Analysis
